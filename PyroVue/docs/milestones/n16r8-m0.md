## Phase B — parallel library implementation

C++ worker-owned files:
- `lib/HistoryStore/Crc32.{h,cpp}`: `persistence::crc32(const uint8_t*,size_t)`, IEEE reflected polynomial 0xEDB88320, initial/final XOR 0xFFFFFFFF; no allocation/table.
- `lib/HistoryStore/CoarseHistoryCodec.cpp`: reuses shared CRC; PVC1 layout/bytes preserved.
- `lib/RunLog/RawLogCodec.{h,cpp}`: namespace rawlogcodec, 32-byte PVR1 header and 24-byte explicit little-endian records. Float bits move through memcpy. Strict bounds/version/reserved/identity/rate/flag/duration/CRC checks; ScanCursor carries nextLogSeq/lastAcqSeq/lastMs/hasPrevious/terminalSeen across pages. A bad/truncated/order-invalid record does not advance the cursor. Time/acquisition gaps are retained data. Terminal ends the prefix.
- `lib/RunLog/EventJournalCodec.{h,cpp}`: namespace eventjournalcodec, 16-byte PVE1 header; length/payload/CRC frames, UTF-8 payload 1..4096 bytes. FrameView borrows caller bytes; no Arduino/JSON/parser/filesystem dependency. Embedded U+0000 is valid framing-level UTF-8; exact JSON/note NUL policy belongs to the M2 reducer/M3 body validator. Decoder output remains unchanged on failure. In-place frame encoding now moves payload **before** writing its length prefix.

Browser worker-owned files:
- `web/src/js/run-protocol.js`: existing IIFE/globalThis.PyroVue convention, independently require-able; reuses ProtocolError when protocol.js was loaded first.
- `web/test/run-protocol.test.js`: inline factories and node:test behavior fixtures; no dependency/framework additions.

Actual JS signatures:

```text
parseRunMeta(value)
parseRunList(value)
parseSnapshot(value, expect?)
  expect={deviceId?,runId?,bootId?}
parseSamplesPage(value, expect)
  expect={deviceId,runBootId,runId,afterLogSeq,throughLogSeq,limit?}
parseEventsPage(value, expect)
  expect={deviceId,runBootId,runId,afterRevision,throughRevision,limit?}
parseMutationResult(value, expect?)
  expect={runId?,operationId?,id?}
normalizeNote(note)
```

Validators return new objects containing declared fields; unknown fields are ignored consistently with existing protocol.js, while declared invalid fields reject. They check schema/status/identity/watermarks, exact request cursor echoes, monotone/consecutive page order, bounded lengths, exact next/count/done coherence and sample flag bits 0..3. Finite temperatures normalize with Math.fround, preserving negative zero; float32 overflow rejects. Null temperature retains its fault instead of becoming zero. Journal tombstones contain no invented timestamp/note/timeBasis; untimed notes retain null ms. Note normalization trims ECMAScript whitespace, rejects NUL/lone surrogates, and enforces 500 Unicode scalars / 2000 UTF-8 bytes. Persisted mutation acknowledgments require persisted:true.

Important future integration boundaries:
- Wire nextBeforeRunId uses null for no next page; C++ store's 0 sentinel must be serialized as null, not accepted as a wire alias.
- JS sample/event pages require their request context to verify captured device/run/origin boot and cursor echoes. The next client must not pass mutable graph selection after awaiting fetch.
- Page validators are stateless; M4 RecordedRunStore must additionally validate **cross-page** acquisition/time/terminal transitions, duplicate contradictions and snapshot progress. Event state/revision conflicts are reducer responsibilities, not a second JSON parser here.
- Snapshot metadata is healthy-only. Corrupt entries remain list/delete UI data, never fabricated zero-history exports.
- The module is not added to the production HTML yet; M4/M6 integrate it in the single offline bundle. Existing wire/browser behavior is unchanged.
